# Prototype (Legacy)

This directory contains the original vanilla HTML/CSS/JS prototype of Gym ERP.

> **DO NOT modify or delete these files.**
> They serve as the reference implementation during the React migration (M1+).

## Files

| File | Purpose |
|------|---------|
| index.html | Complete single-page prototype UI |
| css/variables.css | Original design tokens |
| css/styles.css | Global base styles |
| css/login.css | Login screen styles |
| css/dashboard.css | Dashboard styles |
| css/modules.css | Module/feature styles |
| js/app.js | Router + view switcher |
| js/auth.js | Auth + session engine |
| js/charts.js | Canvas chart renderer |
| js/checkin.js | Check-in modal engine |
| js/data.js | Mock dataset |
